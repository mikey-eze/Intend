SAIF.OS — AOT SHIGANSHINA BUILD

This build fixes the broken space→Earth→world journey and keeps the AOT-style game after Earth.

Journey:
SPACE → GALAXY → EARTH APPROACH → SHIGANSHINA WORLD

Important behavior:
- Scroll input is rate-limited so one large wheel movement cannot skip the cinematic journey.
- Earth has a visible approach phase instead of appearing at full size.
- World entry is one-way once the game is reached.
- The voxel world fades in during the final transition.
- The game is third-person and uses an Eren-inspired player with Mikasa and Armin companions.
- A Colossal Titan event begins automatically after entering the game and attacks the outer wall.
- WASD = move, Shift = sprint, Space = jump, Mouse = camera, Esc = release mouse.
- Click the game after entry to capture the mouse.

Run with a local web server (for example VS Code Live Server). The Three.js module is loaded from jsDelivr.
